# 接线怎么搞（傻瓜版）

> 你不懂电没关系，照着做就行。**核心就一句：强电用大 4P，弱电（信号）用杜邦。
> 两种头子长得完全不一样，插错插不进去。**

## 一句话原则

- **强电（供电）** → **电脑大 4P（Molex）**：一个头同时给 **12V + 5V + 双 GND**，自带防呆插不错正反
- **弱电（信号）** → **杜邦**：GPIO、继电器 IN、舵机信号都用它
- **分电板 / 主干** → **KF 螺丝端子排**（不是插头，是把线锁死的接线板）

大 4P 和杜邦形状差得远，**12V 那根根本插不进 GPIO 排针**，这就是防呆。
（杜邦本身没有防呆，所以信号线一律按下面的颜色约定走，别乱插。）

## 要买的东西（就这几样）

| 东西 | 干嘛用 | 备注 |
| --- | --- | --- |
| **电脑大 4P（Molex）头 + 座** | **强电**：每个设备位一个，给齐 12V + 5V + 双 GND | 用电脑电源那种头，一个头 4 根线 |
| **杜邦公/母头** | **弱电信号**：GPIO、继电器 IN、舵机信号 | 多备几个颜色，按颜色约定接 |
| KF 螺丝端子排 | 分电板（把电分流） | 大电流锁死不发烫 |
| 5A 保险丝 | 母线上防短路烧机 | 强烈建议，几块钱 |

> 手头有杜邦、KF 就用现有的；缺的（大 4P 头/座、保险丝）再买，不贵。

## 先做一块接线板

接线板就是**所有电线的集散地**——电源从这儿进，各设备从这儿出。它是接线的前提，先有板，线才有地方接。

```
        【接线板】
  12V电源 ──► ● 5A保险丝 ──┬──────────┬──────────┬──────────┐
                           │ 大4P #1  │ 大4P #2  │ 大4P #3  │  ← 每个头里都是
  5V 降压 ─────────────────┤12V 5V GND│12V 5V GND│12V 5V GND│     12V + 5V + 双 GND
  GND 汇流排 ──────────────┘   GND    │   GND    │   GND    │
                           └────┬─────┴────┬─────┴────┬─────┘
                                ▼          ▼          ▼
                              步进       水泵       云台
```

| 板上接口 | 接什么 | 用什么 |
| --- | --- | --- |
| **电源进** | 12V 主干、GND（大电流） | 直接锁在 KF 端子排上 |
| **保险位** | 串联 5A 保险 | 防短路烧机 |
| **设备出 ×3** | 电机、水泵+继电器、云台（一位一个座） | **电脑大 4P**：12V + 5V + 双 GND 一个头给齐 |
| **5V 逻辑出** | ESP32 逻辑供电 | 从大 4P 的 5V 取，或独立降压模块出线 |
| **GND 汇流排** | 所有设备的负极 | 都接这儿，保证共地 |

> 说白了就是**一进多出的分线板**：电源一路进，按用途分成几路出，GND 全部汇到一个负极排上。
> 图省事的话，**直接用一块 KF 螺丝端子排（一排螺丝孔）就能当接线板**，不用专门买板子。

## 三步接好

**第 1 步：把电接到接线板上**
12V 电源（粗线，锁在 KF 端子排上）、5V 降压输出、GND 都接进接线板，母线上串 5A 保险。
板上再分出几个**大 4P 座**，每个座都带 12V + 5V + 双 GND；GND 全部连通（都接同一个
负极排，实现共地）。

**第 2 步：接动力（大功率，用粗线）**

| 要接的 | 用什么 | 接到哪 |
| --- | --- | --- |
| 12V → 电机驱动板 | 大 4P（用它的 12V 脚 + GND 脚） | TB6600 的 VCC / GND |
| 12V → 水泵 | 大 4P；浪涌太大就锁在 KF 端子排上 | 经继电器，见下 |
| 电机四根线 | 电机自带的线 | TB6600 的 A+/A−/B+/B− |

**第 3 步：接信号（细线）**

| 要接的 | 用什么 | 接到哪 |
| --- | --- | --- |
| ESP32 控制电机 | 杜邦 | 底盘左驱 `9/10/11`、右驱 `12/13/14` → TB6600 的 `PUL−`/`DIR−`/`ENA−`（当前只接左驱） |
| ESP32 控制继电器→水泵 | 杜邦 | GPIO → 继电器 IN，继电器触点控制水泵 12V 通断 |
| ESP32 控制云台 | 杜邦 | GPIO → 舵机信号线 |

> **水泵这种大功率负载，ESP32 不能直接控制它**（带不动、还会打坏 ESP32）。
> 所以：ESP32 控制**继电器**，继电器再去通断水泵。ESP32 只碰细的信号线，不碰水泵的电。

## 地线怎么接（共地：最容易漏的一根）

**一句话**：全系统只能有**一个**地参考点——所有 GND 各自单独引一根线，回到同一根
**GND 汇流排**（星形，别串成一条链）。

| 谁的地 | 引到哪 |
| --- | --- |
| 12V 电源的 **− 极** | GND 汇流排（动力地，线要粗） |
| 12V→5V 降压模块的 **输入 GND + 输出 GND** | GND 汇流排（各引一根） |
| 两台步进驱动的 `GND` | GND 汇流排 |
| **ESP32-S3 的 GND 排针** | GND 汇流排（细杜邦线即可） |
| 继电器 / 舵机 / 水位传感器的 GND | GND 汇流排 |

> 别"菊花链"：不要让 ESP32 的地从驱动器地上再引一根。虽然也能通，但驱动器换相的地弹会串进
> MCU。全部单独回汇流排、单点接地最省心。

**为什么必须共地（电从哪走）**——以第二批 `OPTO` 款为例，一个脉冲的回路是：

`5V+ → OPTO → 光耦 → PUL → ESP32 GPIO（拉到 0V）→ ESP32 GND → 5V 模块 GND → 回到 5V−`

**所以「ESP32 的 GND」和「5V 模块的 GND」必须是同一个点。** 这条断了，光耦没有回流路径，
现象就是：**接线看着全对、代码也在发脉冲，电机就是不动**（或时好时坏）。
这是共阳接法最常见的"不转"原因。

### 现在：ESP32 用 USB 供电（调试期的做法）

- ESP32 的地此时来自**电脑 USB 的地**，和 12V 电源的地是两套独立参考点 →
  **必须拿一根杜邦线，把 ESP32 板上任意一个 `GND` 排针接到 GND 汇流排**。漏了这根，电机不动。
- **USB 供电时不要往 `5Vin` 再接 5V 模块**：两路 5V 会打架，还可能反灌回电脑 USB 口。
  这个阶段 5V 模块只负责给驱动器光耦公共端（`OPTO` / 六端款的三个 `+` 端）供电。
- **前提**：12V 电源得是**隔离型**（普通开关电源 / 适配器都自带变压器隔离）。若共地后摸机壳
  有麻感，那是电脑适配器的 Y 电容漏电，改用**笔记本电池**（拔掉适配器）调试最干净。
- **调试最稳的组合**：ESP32 插电脑 USB 看串口 + 一根 GND 回汇流排 + 驱动器 12V/5V 全走自己的电源。

### 以后装机：ESP32 改从 5V 模块取电

- 拔掉 USB，`5Vin` ← 5V 模块输出；GND 仍回汇流排。
- **别和步进驱动共用同一条细 5V 线**：电机启停的压降与反电动势会把 MCU 拉到复位
  （随机重启、Wi-Fi 掉线）。给 MCU 单独一路输出，或 `5Vin` 就近并 470µF + 0.1µF，线加粗。

### 接完怎么验（10 秒）

**断电**，万用表通断档：量 **ESP32 的 GND 引脚 ↔ 12V 电源 − 极**，应该**通（≈0Ω）**；
顺带量 5V 模块 GND、两台驱动的 GND，任意两点都该是通的。有一个不通，就是那根线漏了。

## 步进电机 ↔ 驱动器怎么接（重点）

一个步进 = 一块 TB6600 = **三组线，别混**：一组电源（粗）、一组信号（细）、一组电机（4 根）。

```text
   大 4P（一个头给齐 12V + 5V + 双 GND）      ESP32-S3
              │                              │ 细线
              ▼                              ▼
 ┌────────────────────────────────────────────────────┐
 │                      TB6600                       │
 │  VCC / GND           ← 大 4P 的 12V / GND（动力）   │
 │  PUL+ / DIR+ / ENA+  ← 大 4P 的 5V（共阳）         │
 │  PUL− / DIR−         ← GPIO（低电平有效）           │
 │  ENA−                ← GPIO 经 NPN 汇聚（脱机控制）  │
 │  A+ / A− / B+ / B−   → 电机 4 根线                 │
 └────────────────────────────────────────────────────┘
```

**对照表（一驱一机；4 套都照这个接）**

| 从哪 | 到哪 | 用什么 |
| --- | --- | --- |
| 大 4P：**12V 脚 + GND 脚** | TB6600 `VCC` / `GND` | 动力（粗线） |
| 大 4P：**5V 脚** | TB6600 `PUL+` `DIR+` `ENA+`（三个并联） | 这就是"共阳"——同一个头里就带 5V |
| ESP32 GPIO（STEP / DIR） | TB6600 `PUL−` / `DIR−` | 杜邦（弱电信号） |
| ESP32 GPIO（EN，**每台一条**） | TB6600 `ENA−` | 杜邦；**左驱 `GPIO11`、右驱 `GPIO14`**（各十几 mA，可直驱）。引脚以 [[electrical-architecture]] §5.2 为准，本表同步 |
| ESP32 GND ↔ 12V GND | 接到同一个负极排 | **必做**（不共地，共阳接法不成立） |
| 电机 4 根线 | TB6600 `A+` `A−` `B+` `B−` | 电机自带的线 |

> 上表是**有 `PUL+/PUL−` 六端款**的接法。另一批驱动是**单端款**：信号端子为
> `PUL` / `DIR` / `ENA` + 一个 **`OPTO`** 公共端——**`OPTO` 接 +5V**（不是把 5V 接到
> `PUL` 上），`PUL`/`DIR` 接 GPIO，照样是**低电平有效**，两批板子可以混用。
> 详见 [[stepper-wiring]] §2.1「`OPTO` 公共端的单端款」。

**接电机那 4 根线的规矩**

1. 先认出两组线圈：万用表量通断，**导通的两根就是一组**（A 组、B 组各两根）。
2. 接反只影响转向，不会烧。转向不对就把**同一组的 `A+` / `A−` 对调**。
3. 电机线出厂是杜邦 4pin，TB6600 是螺丝端子 → 剪头压端子，或用杜邦转端子转接，别硬塞。
4. **通电时绝对不要拔插电机线**：TB6600 这类驱动器带电断线容易炸管。
5. 通电前先照拨码表把**电流档设成电机额定值以内**（见 [[stepper-wiring]] §4），再上电。

> 拨码（细分 / 电流）、脉冲宽度、引脚避让、共阳为什么这么选——这些"为什么"见
> [[stepper-wiring|步进驱动接线与供电]]；本文件只说**怎么接**。

## 单个 ESP32 能带多少设备

| 设备 | 一个占多少 | 本项目要接 | 卡在哪儿 |
| --- | --- | --- | --- |
| **步进电机** | **3 个引脚（PUL+DIR+ENA）** | **4 台 = 12 脚** | 只算 GPIO；「多轴同时动」才卡软件。每台各自一个 3 连排（底盘左驱 `9·10·11`、底盘右驱 `12·13·14`、步进3 `4·5·6`、步进4 `15·16·17`），见 [[electrical-architecture|电气系统架构]] §5.3 |
| **云台（舵机）** | 1 个 PWM 通道 | **2 个**（1 套 2 轴） | 硬件 PWM 通道数（共 8 个） |
| **继电器 / 水位** | 1 个引脚 | **3 个**（2 继电器 + 1 传感器） | 电源功率，跟 ESP32 无关 |

> **步进不是「只能 2 个」**：轮流动（一次动一两个轴）接 4 个没问题，只算 GPIO 够不够；
> 只有要求**多轴同时动 / 插补**时才吃紧，那要换 ESP-IDF（硬件发脉冲）或加多轴驱动板。
> 具体哪个设备分到哪个 GPIO 是**架构层**的事，见 [[electrical-architecture|电气系统架构]] §5；
> 本文件只讲**用什么端子/插头接**。

## 颜色好认（可选）

**自己接的线**（杜邦 / KF 到设备侧）按这套认：红=12V+、黑=GND、橙=5V、蓝=STEP、绿=DIR。

> ⚠️ **电脑大 4P 的出厂线色是另一套，别混着认**：**黄=+12V、黑=GND、黑=GND、红=+5V**
> （四根线的顺序就是 黄-黑-黑-红）。大 4P 上**红是 5V，不是 12V**，也**没有橙线**——
> 「橙=3.3V」是电脑主板 24pin 的规矩，大 4P 用不上。
> 杂牌电源 / 延长线 / 模组线颜色不一定标准，**第一次上电前量一下**：万用表黑笔搭黑线（GND），
> 红笔搭黄线应读到 ≈ +12V，搭红线应读到 ≈ +5V。

有颜色更好认，但没有也不影响——防呆靠头子，不靠颜色。

## 未来要加东西（已规划的扩展位）

本次确定要留的三样：**+2 步进**、**1 套水泵（2 继电器 + 1 水位）**、**1 套 2 轴云台**。
每个扩展位留**两个头子**：一个强电（大 4P：12V + 5V + 双 GND）+ 一个弱电（杜邦，接 ESP32）。
两个头子型号不同，插不错。共留 4 个位置（3 个已定 + 1 个备用），清单见
[[electrical-architecture|电气系统架构]] §6。
