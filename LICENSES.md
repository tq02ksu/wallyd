# Licensing

WALLY uses a split license model:

- **Software:** Apache License 2.0, in [LICENSE](LICENSE).
- **Documentation:** Creative Commons Attribution 4.0 International (CC BY
  4.0), in [docs/LICENSE](docs/LICENSE).

## Apache-2.0 scope

Apache-2.0 applies to executable source and machine-readable implementation
artifacts, including:

- `agentd/`, `robotd/`, and `src/` source code;
- `firmware/`;
- executable files under `scripts/`;
- `contracts/` and generated contract artifacts;
- shell, TypeScript, JavaScript, Python, Swift, configuration, and CI workflow
  source unless a file says otherwise.

## CC BY 4.0 scope

CC BY 4.0 applies to explanatory and design content, including:

- `docs/`, excluding `docs/LICENSE`;
- `README.md` and `AGENTS.md`;
- Markdown evaluation reports under `eval/`.

Code samples embedded inside documentation remain available under Apache-2.0.

## Attribution

Suggested attribution for documentation reuse:

> WALLY documentation by tq02ksu and WALLY contributors, licensed under CC BY
> 4.0. Source: https://github.com/tq02ksu/wallyd

Third-party libraries, tools, models, and generated artifacts retain their own
licenses.
