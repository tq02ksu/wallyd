## 1. 核心（2026-09-26 定稿）

> 给出一路 **12V 稳定电压**，经 **12V 逆变器** 转 **220V/100V** 供 Mac mini。整机预算按此核心
> **≈400**。坞站「边充边放 / ORing」**暂不实现**，降级为未来可选组件（见 §9）。

| 状态 | 期望 |
| --- | --- |
| 正常运行 | 电池（或外接 12V 电源）提供 **12V**，经逆变器供 **220V/100V** 给 Mac mini |
| 底盘/外设 | 同一块 12V 母线的其余分支供步进、水泵、云台（见 [[electrical-architecture]]） |

即「**一块 12V 电源 + 一个逆变器**」，先让 Mac mini 动起来，不做复杂切换。

## 2. 拓扑（核心）

```text
  能量源：电池包 18.5V 或 12V 电源 / 适配器
        │
        ├─ 5S→12V 降压（或直接用 12V 电源）──► 12V 母线
        │
        └───────────────────────────────► 12V 母线
                                               │
                       ┌───────────────────────┼─────────────────────────────┐
                       ▼                       ▼                             ▼
              ┌───────────────┐        ┌───────────────┐            ┌──────────────┐
              │ 12V 逆变器     │        │ 步进/TB6600   │            │ 水泵/云台     │
              │  → 220V/100V  │        │ (动力)         │            │ (动力,经继电器) │
              └───────┬───────┘        └───────────────┘            └──────────────┘
                      ▼
              ┌───────────────┐
              │  Mac mini     │
              └───────────────┘
```

- **12V 是核心稳压轨**：动力、逆变器能量都从这一路取。
- **逆变器（12V→220V/100V）**：给 Mac mini 供电，是整机最大的一项（见 §4 电流量级）。
- 逻辑 5V / 3.3V 另从 12V 降压，见 [[electrical-architecture]] 与 [[wiring-connectors]]。

> ⚠️ **关于「边充边放」**：已明确**暂不实现**（2026-09-26）。其原理与方案拆解保留在
> §9，作为未来可选扩展，不在核心拓扑里。

## 4. 电流量级（核心：12V + 逆变器）

- 12V 母线（Mac 逆变器）：150W ÷ 12V ÷ 0.85 ≈ **14.7A**
- 电池侧（18.5V）：≈ **10A**
- 浪涌：逆变器启动给输出电容充电，可达额定 2–3 倍（12V 侧 30–40A，持续数十 ms）

> 2026-09-26 定位：本文档以「12V 稳压 + 逆变器供 Mac」为核心。底盘 2×42 步进（2–3A）、
> 水泵、云台、逻辑轨等负载及余量见 §10（这些是**平台扩展**，不是 Mac 供电核心）。

## 5. 三个真实风险（核心需注意）

1. **浪涌触发 BMS 过流保护 —— 最可能翻车的一点**。工具包 BMS 按工具工况设定，30A 级浪涌
   可能直接跳保护。缓解：软启动、预充电阻，或选带软启动的逆变器。
2. **降压模块电流选型不足**：`5S→12V` 只按 14.7A 就需 ≥15A 以上，别选太小的。
3. **散热**：逆变器满载约 85% 效率 → 20W+ 废热，叠加 Mac mini 与 buck 损耗，
   封闭小车内的热设计是真问题。

## 6. 验证步骤（桌面 PoC）

1. **逆变器带 Mac**：12V 电源 → 逆变器 → Mac mini，看是否正常开机、供电稳定。
2. **浪涌测试**：冷启动逆变器 20 次，观察电池包 BMS 是否跳保护，记录母线压降。
3. **续航与功耗**：记录离坞续航、12V 输入功率、逆变器效率。

## 9. 可选组件：坞站「边充边放 / USB 设备 UPS」（未来扩展，当前不实现）

> 2026-09-26 用户决策：**先不纠结边充边放，放一边**。本节省略为「未来可选组件」，
> 保留原理要点，作为**后面扩展**用，不作为整机一部分。

### 9.1 它是什么（未来形态）

- 坞站在线时给 Mac mini 供电 + 给电池充电；离坞时电池无缝接管。
- 作为 **USB 设备 UPS** 形态的可选组件：插上即得到「插电使用」体验，不插就纯电池供电。

### 9.2 原理要点（为什么难）

- 工具电池包为**同口保护板**（充放共用 B+/B-）：电池即母线，充电器只能测到总电流，
  看不到电池支路 → CC/CV 终止逻辑失效 → 不停充或误判。
- 解法是「**让电池成为支路而非母线**」：坞站在线时母线由坞站供，电池支路被
  理想二极管/负载开关截止，只保留充电路径。
- 关键器件：理想二极管 / ORing（20A），`24V→12V` 与 `5S→12V` 降压、CC/CV 充电模块。

### 9.3 何时启用

- 当需要「**边充边用、拔插不断电**」体验时，作为独立组件接入。
- **启动前提**（当前不阻塞，留待未来）：先确认工具电池包是否接受第三方 CC/CV 充电、
  是否改分口保护板、ORing 切换是否无死区（原 §2–§7 验证项）。

## 10. 平台扩展负载（非 Mac 供电核心）

> 本项目是「平台」而非成品（见 [[product-positioning]]）。2026-09-27 用户确定扩展清单：
> **+2 步进**、**1 套水泵（2 继电器 + 1 水位传感器）**、**1 套 2 轴云台**。
> 引脚分配、功率余量核算与扩展位清单见 [[electrical-architecture]] §5–§7（本文不重复明细）。

结论：

- 加入上述扩展后，12V 侧峰值约 **25A 量级**（Mac 逆变器占大头）。
- `5S→12V` 降压要按 **≥30A** 选，或把**逆变器与动力分两路**从电池取电。
- 逻辑轨（5V）与舵机轨（5V/6V）各走一路独立降压，不与 MCU 共用。
- 保护：母线加保险丝 / 电流采样；水泵与逆变器加软启动，避免浪涌触发 BMS 过流保护（§5 风险 1）。
